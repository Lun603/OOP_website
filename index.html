🌿 2. Git (MINGW64) & Terminal 實用指令寶典

🎓 課堂重點：Git 控制版本的三大核心區域觀念

Git 是如何管理程式碼演進歷史的？底層分為三大運作區域：

  1. 工作區 (Working Directory)：你當前編輯檔案的實際資料夾目錄。
  2. 暫存區 (Staging Area / Index)：執行 git add 後，準備好要上傳與記錄的檔案清單。
  3. 儲存區 (Repository)：執行 git commit 後，正式打包儲存並標記目前版本的節點。

💡 工作流程：工作區修改程式 → git add 入暫存區 → git commit -m 歸檔標記版本！

建構與版本提交指令：

git init

建立工作區域：在當前目錄初始化 Git 儲存庫，產生隱藏的 .git 資料夾來紀錄歷史。

git status

檢視當前狀態：查看有哪些檔案被修改。🔴 紅色代表未進暫存區，🟢 綠色代表已進入暫存區。

git add <檔案> / git add .

丟進暫存區：將檔案從工作區丟進暫存區。git add . 可一次加入全目錄修改。

git commit -m "版本說明"

提交正式版本：將暫存區的檔案正式打包提交至儲存區，並附上本次修改的說明標記。

歷史、重置與分支管理指令 (進階)：

git log / git log --oneline

查看 Git 日誌：顯示過往所有 commit 的歷史紀錄、作者、時間點以及 commit ID 前 7 碼。

git reset --soft <commit ID>

重置 commit 紀錄 (溫和)：回到指定版本點。--soft 模式會保留你目前工作區與暫存區的程式碼。

git diff

比較檔案差異：比較「工作區」與「暫存區」之間程式碼詳細修改的行數差異。

git branch / git switch -c <分支名>

分支管理：git branch 查看所有分支；git switch -c new-feature 建立並切換至新開發分支。

git stash / git stash pop

暫存工作進度：把尚未完工的程式碼暫時隱藏封存起來，切換分支處理突發 Bug 後再用 pop 還原。

git remote add origin <URL> / git push

遠端同步 (GitHub)：將本地端的儲存區連結至 GitHub 遠端庫，並執行 git push -u origin main 推送上傳。

CMD / MINGW64 基礎終端機指令：

cd <位址> / cd ..

切換目錄：cd /c/ 移動至特定路徑；cd .. 離開並回到上一層資料夾。

dir / ls -a

查看目錄內容：dir (Windows) 或 ls -a (Bash) 列出當前目錄所有檔案（含隱藏檔）。

mkdir 【資料夾名稱】

建立新資料夾：在當前目錄下新增一個指定名稱的新資料夾。

notepad <檔案.txt>

記事本開啟檔案：使用 Windows 預設記事本文字編輯器直接打開指定文字檔。

clear / cls

清空終端機畫面：clear (Git Bash) 或 cls (Windows CMD) 清理當前視窗雜亂的輸出。

🔬 4. 高階 OOP 與記憶體細節解析

1. Stack vs Heap 記憶體配置 (物件生命週期)

  • Book b("C++", 101);：配置於 Stack (堆疊)。離開大括號範疇時自動呼叫解構子銷毀，速度極快且絕不洩漏。
  • Book* b = new Book("C++", 101);：配置於 Heap (堆積)。必須手動 delete b; 釋放，若忘記會造成 Memory Leak。現代 C++ 鼓勵採用 RAII 機制（如 std::vector 或 std::unique_ptr）自動管理 Heap。

2. RAII (Resource Acquisition Is Initialization) 資源獲取即初始化

C++ 最核心的哲學：將資源（動態記憶體、檔案控制代碼）的生命週期綁定至 Stack 物件的生命週期。當物件宣告時（建構子）向系統要資源，物件離開範疇（解構子）自動還資源。我們的 std::vector<Book> 即完美實現了 RAII。

3. 初始化列表 vs 大括號賦值

在建構子中使用 : name(bookName) 屬於初始化階段，直接在分配記憶體時放入數值（1 次複製）。若在大括號內寫 this->name = bookName;，會先觸發預設建構子產生空物件，再執行賦值（2 次記憶體開銷）。

4. std::sort 比較邏輯與 (a, b) 參數

std::sort 排序時會將元素兩兩抽出比對。Lambda 回傳的 bool 值代表「第一個參數 (a) 是否應該排在第二個參數 (b) 的前面」：

  • a.getID() < b.getID()：當 a 比 b 小回傳 true 放在前面 → 升冪排序 (由小到大)
  • a.getID() > b.getID()：當 a 比 b 大回傳 true 放在前面 → 降冪排序 (由大到小)

💡 5. C vs C++ OOP 對照表

概念 C 語言做法 C++ 物件導向做法
資料封裝 struct 成員全公開，外部可自由修改 使用 private 保護成員，僅透過 Getter 存取
初始化 手動呼叫 init(&b)，忘記會讀到垃圾值 建構子 自動觸發，確保誕生時資料有效
資源回收 手動 free()，容易記憶體洩漏 解構子 (RAII) 在離開作用域時自動回收
動態陣列 手動 malloc() + realloc() 管理長度 使用 std::vector，自動伸縮記憶體並維護生命週期
